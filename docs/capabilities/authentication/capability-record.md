## Cross-capability note — Authentication accountability (14 November 2026)

**Established:** Authentication owns credential, sign-in and session outcomes; security policy requires proportionate structured auditable security events. **Proposed:** [Audit](../audit/capability-record.md) receives appropriately minimised authenticated producer assertions about sign-in attempts, assurance and revocation, distinguishing failed attempts from confirmed actions; credentials, tokens and raw sessions never become its standard payload. **Open:** capture guarantee, producer verification and risk-driven fail-closed operations. Authentication's conceptual review remains incomplete.
