## Cross-capability review note — Enrolment (provisional)

**Enrolment reciprocal interface (proposed; 17 November 2026; [Enrolment review PR #60](https://github.com/nuxt-layers/architecture-blueprint-review/pull/60)).** Course owns published offering/cohort identity, admission parameters, revisions, learning outcomes and any Course-owned seat supply. Enrolment consumes these as versioned facts and owns individual application/admission/withdrawal status, supplying authorised roster/participation evidence back. When Booking or Course owns seats, Enrolment must use its checked capacity contract and cannot create a competing pool. This note is not Course review approval or an implemented contract.
